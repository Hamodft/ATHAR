# أثر — عرض عملي

واجهة عربية لتحويل الإجابات البسيطة إلى صفحة مهنية.

- `/`: رحلة الإدخال والمعاينة؛ حفظ محلي فقط.
- `/profile`: نموذج مكتمل ببيانات افتراضية.
- لا توجد مفاتيح أو بيانات مستخدمين أو ربط حسابات في هذه النسخة.
- إعادة الصياغة والحفظ الدائم مستمران في مشروع العمل الخاص ولم يتم نقلهما هنا.

Deploy as a static Vercel project with no build command.
