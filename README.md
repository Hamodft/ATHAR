# أثر — منصة الحضور المهني

رحلة عربية بسيطة لتحويل إجابات المستخدم إلى صفحة مهنية يراجعها ويختار نشرها.

## الميزات

- أسئلة تدريجية، خبرات متعددة، تعليم، مهارات وموقف مهني.
- معاينة البروفايل بثلاثة ألوان، وصورة شخصية اختيارية.
- سيرة نصية عربية مخصصة للطباعة وحفظ PDF من المتصفح.
- حسابات بريد وكلمة مرور عبر Supabase Auth، ومسودات خاصة مرتبطة بالحساب.
- صور في حاوية خاصة، وصفحات منشورة منفصلة عن المسودات، مع إلغاء النشر.
- `/profile` نموذج افتراضي، `/p/<slug>` صفحة منشورة، `/cv` معاينة السيرة.

## التشغيل

`npm ci` ثم `npm test` ثم `npm run build` ثم `npm run dev`.

Vercel: Build command `npm run build`, output `dist`, install `npm ci`.

`config.js` يحتوي عنوان Supabase ومفتاح publishable المسموح استخدامه في المتصفح. لا تضع مفاتيح service_role أو أسرار API في هذا الملف.

`database/schema.sql` يوثق المخطط المطبق عن طريق Supabase، بما فيه سياسات عزل البيانات والصور. لا تُعد تشغيله فوق الجداول الموجودة دون ترحيل مُراجع.

## متطلبات تفعيل التسجيل العام

اضبط Site URL وRedirect URLs في Supabase على رابط الإنتاج، مع بقاء تأكيد البريد مفعّلًا. اضبط SMTP مخصصًا؛ خدمة الإرسال الافتراضية مخصصة للتجربة وقد تمنع الإرسال لغير أعضاء المؤسسة. لا تعتبر وجود نموذج التسجيل اختبارًا لوصول الرسائل. ينبغي إكمال اختبار حساب حقيقي، واستعادة كلمة المرور، ورفع صورة واسترجاعها من جهاز ثانٍ قبل إطلاق التسجيل العام.

إعادة الصياغة بالذكاء الاصطناعي ما زالت غير مفعّلة. التصدير يستخدم طباعة المتصفح، وليس خدمة PDF مستقلة. لم تُنقل مسودات نسخة Sites الخاصة إلى Supabase تلقائيًا.

## صفحات الحساب والإدارة

- `/dashboard`: لوحة المستخدم وحالة اكتمال المعلومات والحفظ.
- `/edit`: تعديل المعلومات والخبرات والصورة والتواصل.
- `/design`: خمسة قوالب وثلاث لوحات لونية وخطوط ومسافات وترتيب أقسام مع معاينة مباشرة.
- `/my-profile`: المعاينة الخاصة وتصدير السيرة ومراجعة النشر وإلغاؤه.
- `/suggestions`: إرسال مشاركة خاصة ومتابعة حالتها والرد.
- `/about`: التعريف بأثر.
- `/admin/overview`: أعداد حقيقية للمستخدمين والمسودات والمنشور والمشاركات الجديدة.
- `/admin`: قائمة المستخدمين والصفحات وإلغاء النشر والرد على المشاركات.

تستخدم الصفحات الحساب والحفظ والنشر نفسهما؛ لا تُنشر تعديلات المسودة تلقائيًا. يحفظ `publicContent` خيارات التصميم المعتمدة فقط، ويستبعد التواصل ما لم يطلب صاحبه إظهاره.

`database/workspace.sql` يوثق الإضافات المطبقة. صلاحية الإدارة مرتبطة ببريد مؤكد في `athar_private.admin_emails`، مع التحقق من `auth.users` في قاعدة البيانات. لا يمكن للمستخدم تعديل قائمة المسؤولين أو حالة مشاركته. لا تعتمد الصلاحية على بريد يرسله المتصفح أو `user_metadata`. الواجهات العامة لدوال الإدارة تعمل بصلاحية المستدعي، والدوال الداخلية ذات الامتيازات تتحقق من هوية المسؤول. لا تُعرض مسودات المستخدمين للإدارة؛ تظهر أعدادها فقط.

اختبارات `workspace.test.mjs` تفحص تفاعل النماذج والتنقل والتصميم والاقتراحات بعزل البيانات، إضافة إلى اختبارات الجلسة ونقل السيرة. فُحصت سياسات قاعدة البيانات بمعاملات اختبارية جرى التراجع عنها.

## استيراد السيرة

`/import-cv` متاحة قبل التسجيل ومن قائمة الحساب و«معلوماتي». تُقرأ ملفات PDF النصية وDOCX داخل المتصفح، بتحميل مكتبات القراءة عند الحاجة فقط. حد الملف ١٠ ميجابايت، وPDF حتى ٣٠ صفحة، والنص حتى ٨٠ ألف حرف. تُفحص أحجام أرشيف DOCX قبل فتحه. يوجد بديل للصق النص عند تعذر القراءة؛ لا يوجد OCR للملفات المصورة.

الاستخراج تنظيم أولي بعناوين الأقسام العربية والإنجليزية؛ لا يستخدم نموذج ذكاء اصطناعي، ولا يضمن فهم كل تنسيقات السير. تُعرض المعلومات كحقول قابلة للتعديل، والخبرات تحتاج مراجعة توزيعها. الحقول التي لها قيمة حالية لا تُحدد تلقائيًا، واستبدالها يتطلب موافقة صريحة. تُضاف الخبرات للقائمة افتراضيًا، ولا تُحذف خبرات زائدة بصمت. يبقى أصل النص ظاهرًا للمقارنة إلى أن تُطبّق المعلومات. الملف نفسه لا يُرفع ولا يُحفظ في الحساب، والنشر وحفظ الحساب منفصلان عن الاستيراد.

فُحص استيراد PDF وDOCX تجريبيين في المتصفح حتى معاينة البروفايل، وتغطي الاختبارات اختيار الحقول وحماية القيم الحالية وحدود الخبرات والأرشيف.

## تحسينات التجربة المنقولة
نُقلت تحسينات الحركة والوصول من آخر نسخة Sites مع الحفاظ على التصميم القديم وجميع ميزات هذه المنصة. تشمل المثال التفاعلي، وتنقل لوحة المفاتيح، وتركيز أخطاء الإدخال، ومؤشر التقدم، وGSAP مع تقليل الحركة وتنظيف المؤثرات عند تغيير الشاشة. لم تُنقل بيانات الحسابات أو مسودات المتصفح بين النطاقين تلقائيًا.


## قالب الحضور المهني

قالب داكن وآخر فاتح مستوحيان من المرجع المهني، مع الألوان والخط والمسافات وترتيب الأقسام. المثال `/profile` يتيح تجربة التصميم دون تغيير مسودة الزائر. `/design` يتيح تخصيص مسودة الضيف وحفظها محليًا؛ حفظ الحساب والنشر يبقيان إجراءين منفصلين. لا تظهر الأقسام الفارغة، ولا تُنقل بيانات المثال إلى ملف المستخدم. تفاصيل التنفيذ والتحقق في `PORTFOLIO-IMPLEMENTATION.md`.


## Arabic and English profiles

All five profile templates support an Arabic / English switch and mirrored reading directions. Add reviewed English fields and experiences under English profile content in /design or /edit. Arabic content remains unchanged, and both languages use the same design and contact-sharing choices. No automatic translation or new external processing service is used. Missing English content falls back to the original with a visible notice. The fully translated demonstration is available at /profile?lang=en. Printable CVs also support language selection.

The applied database/bilingual.sql documents the additional English content key in published JSON snapshots; ownership policies and publication permissions are unchanged. Existing public pages change only after the user reviews both languages and publishes again.
